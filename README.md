Grandma's Kitchen is a modern website concept for a small-scale fast food business. The project showcases warm, welcoming branding, recipe highlights, and a clean layout designed to attract customers and present the business professionally.

## About the Enterprise

Grandma's Kitchen is a home-style food brand focused on delicious, affordable, and comforting meals. This website is designed to help customers explore signature dishes, view recipe inspiration, and connect with the business.

## Features

- Clean and attractive landing page layout
- Business branding and logo display
- Recipe cards with ingredients and steps
- Clear navigation and responsive design styling
- Footer with business copyright information
